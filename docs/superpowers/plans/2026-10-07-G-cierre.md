### Task G2: Prueba de punta a punta (la hace el orquestador)

**Files:**
- Create: `scripts/e2e_orquestacion.py`, que se queda en el repo como prueba manual reproducible.

**Escenario:**
1. Levantar un upstream falso OpenAI-compatible en `127.0.0.1:8291` (stdlib `http.server` en un hilo):
   - Con la llave `bad` en `Authorization` responde 429 `{"error":{"message":"rate limit"}}`.
   - Con la llave `good` responde 200 con un stream SSE OpenAI ("hola").
2. Crear un `LITELLM_CONFIG_DIR` temporal con:
   - Un `.env` con `UI_API_KEY=bc-e2e`, `FAKE_KEY=bad` y `FAKE_KEY_2=good`.
   - Un `providers.json` con el provider `fake` (`api_base` `http://127.0.0.1:8291/v1`, `auth_env_var` `FAKE_KEY`, `extra_auth_env_vars` `["FAKE_KEY_2"]`, `active_model` `fake-model`) como activo.
   - Delegación habilitada, con el workspace temporal permitido y `allow_request_verify=true`.
3. Levantar el backend del worktree: `python -m uvicorn app.main:app --port 8100`, con ese `LITELLM_CONFIG_DIR` en el entorno y `cwd=backend`.
4. Afirmaciones:
   - `POST /v1/messages` (formato Anthropic) devuelve 200, con `x-bipolar-target: fake#1` y `x-bipolar-attempts: 2`, y el texto "hola" en el stream.
   - `GET /api/providers/fake/credentials` muestra el slot 0 en `cooling` y el 1 en `available`.
   - `POST /mcp`: `initialize` → `serverInfo.name == "bipolar-code"`; `tools/list` → 5 herramientas.
   - `tools/call delegate` con un `agent` inexistente o `verify` inválido → `isError: true`. No se lanza ningún CLI real.
   - `GET /api/accounts/pick?adapter=claude` → `{"mode": "proxy", ...}` (no hay cuentas en el config temporal).
   - `python scripts/bipolar_claude.py --bc-dry-run` con `BIPOLAR_URL=http://127.0.0.1:8100` y `BIPOLAR_API_KEY=bc-e2e` → `mode == "proxy"`.
5. Apagar todo y borrar las carpetas temporales.
